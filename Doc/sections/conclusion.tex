\section{Conclusion}
We introduced \texttt{MPSSM-PCG}, a learned preconditioner for graph-structured
linear systems based on MPSSM. \texttt{MPSSM-PCG} achives preconditioning
quality comparable to an existing learned preconditioner while requireing
substantially lower setup time. Furthermore, we showed that the learned
operator $P_\theta \approx (I + \alpha L)^{-1}$ can be used as a long-range
graph propagation operator. The learned operator substantially improves the
performence of shallow GCNs enabling long-range propagation to be achieved
using fewer layers.

\subsection{Limitations}
Main limitation arrise from our limited computation budget. First, the
multilayer long-range propgation in table \ref{tbl:echo_sssp_layers} is
conducted using a single value of $\alpha$, so evalutaing the relation between
propogation depth and $\alpha$ more extensively could provide a better image of
the effect of the learned operator.

Second, we considered operators of the form $I + \alpha L$ only. Other
long-range graph operators like $e^{-tL}, L^\dagger$ could also be considered,
as they could be more suitable for differnet graph-learning tasks.

Finally $\texttt{MPSSM-PCG}$ is specifically designed around graph-structured
sparse systems and was evaluated on systems computed from graph-learning
datasets. Its effectiveness on more general sparse SPD matrices remains to be
investigated.
